# maxarm_petri

The lab bench with the xArm6 on its rail (the room's controllable robot, idle)
and the Hiwonder MaxArm standing on the bench in front of the rail, three
90 mm Petri dishes (lid on) on an arc in front of it and a set-aside spot for
each lid. Built for `scripts/maxarm_lid_twin.py`: lift each lid, set it
aside, put it back, graded on where the lid body ends up.

`room.json`, `petri_base.xml` and `petri_lid.xml` are GENERATED by
`make_room.py` from `hardware/maxarm/petri.py` (dish dimensions, layout, the
MaxArm's base pose); edit there and rerun it. `hardware.maxarm.test_sim_maxarm`
fails when they are stale. The dish dimensions are assumed standard until
measured on the real dishes.

```bash
python rooms/maxarm_petri/make_room.py
python -m twin_rooms view maxarm_petri
MUJOCO_GL=egl python scripts/maxarm_lid_twin.py run --video out.mp4
```
